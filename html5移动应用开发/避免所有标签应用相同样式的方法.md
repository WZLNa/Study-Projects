# 避免所有标签应用相同样式的方法

如果你希望只对特定的标签应用样式，而不是影响页面上所有的段落，可以使用以下几种方法：

## 方法一：使用 class 类名（推荐）

```html
<style>
  .highlight {
    color: red;
    font-weight: bold;
  }
</style>

<p>这是普通段落</p>
<p class="highlight">这是特殊样式的段落</p>
<p>这也是普通段落</p>
```

## 方法二：使用 id 选择器（适合唯一元素）

```html
<style>
  #special {
    color: blue;
    font-size: 18px;
  }
</style>

<p>普通段落</p>
<p id="special">这个段落有特殊样式</p>
```

## 方法三：使用内联 style（直接写在标签上）

```html
<p>普通段落</p>
<p style="color: green; font-size: 20px;">这个段落有特殊样式</p>
```

## 方法四：使用更具体的选择器（如容器内）

```html
<style>
  .content p {
    color: purple;
  }
</style>

<div class="content">
  <p>这个段落会应用样式</p>
</div>

<p>这个段落不会应用样式</p>
```

## 方法对比

| 方法       | 优点                 | 缺点                 | 推荐度 |
| ---------- | -------------------- | -------------------- | ------ |
| class      | 可复用、易维护       | 需额外添加类名       | ⭐⭐⭐⭐⭐  |
| id         | 精确控制单个元素     | 不可复用             | ⭐⭐⭐⭐   |
| 内联 style | 快速、无需额外选择器 | 不利于维护、无法复用 | ⭐⭐     |
| 容器选择器 | 批量控制、结构清晰   | 依赖 HTML 结构       | ⭐⭐⭐⭐   |

## 最佳实践建议

```html
<style>
  /* 基础样式（可选） */
  p {
    line-height: 1.6;
  }

  /* 特殊样式通过类名控制 */
  p.important {
    color: #d32f2f;
    font-weight: bold;
  }

  p.note {
    background: #fff3cd;
    padding: 10px;
    border-left: 4px solid #ffc107;
  }
</style>

<p>普通段落</p>
<p class="important">重要提示</p>
<p class="note">备注信息</p>
```

**推荐使用 class 方式**，它既灵活又易于维护，是前端开发中的最佳实践。
